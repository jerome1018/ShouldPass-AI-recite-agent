📖 ShouldPass 使用指南

第一步：获取 API Key

ShouldPass 需要调用大模型来梳理题目和批改答案。你需要一个 LLM 的 API Key：

  • DeepSeek（推荐，便宜）：
    打开 https://platform.deepseek.com/api_keys
    注册/登录 → 点击「创建 API Key」→ 复制保存
    Base URL: https://api.deepseek.com | Model: deepseek-chat
  • OpenAI：
    打开 https://platform.openai.com/api-keys
    创建 API Key → 复制保存
    Base URL: https://api.openai.com/v1 | Model: gpt-4o
  • 其他兼容接口（Ollama / Groq / 硅基流动 等）：
    只要支持 OpenAI 兼容的 /chat/completions 端点即可
    填入对应的 Base URL + Model 就行

⚠️ API Key 只保存在你的浏览器本地，不会上传到任何服务器。

第二步：配置 ShouldPass

点击右上角 「⚡ 配置API」 按钮，填入：

  • API Key：上一步获取的 key（sk- 开头）
  • Base URL：API 地址（默认已填好 DeepSeek）
  • Model：模型名称
  • 点击「保存配置」

首次访问时，上传区会自动显示配置面板，直接在那里填也可以。

第三步：上传文档生成题库

在「📄 生成题库」页面，拖拽或点击上传你的学习文档：

  • 支持 .md / .txt / .pdf / .docx 格式
  • 文档里应有题目 + 参考答案（格式不限，LLM 会自动梳理）
  • 上传后 LLM 自动提取题目、润色答案、生成关键词
  • 大文档（3万+ 字）会自动分片处理，耐心等待即可

第四步：开始答题

题库生成后，点击「开始答题」或切换到「✏️ 答题」标签：

  • 随机出题，你在文本框里作答（支持多行）
  • Cmd/Ctrl + Enter 提交答案
  • LLM 逐关键词对照参考答案，给出 1-5 分评价
  • 指出你答对的部分、遗漏的关键点、错误的地方
  • 答题记录保存在浏览器本地，下次打开还在

小技巧

  • 源文档写得越详细，批改越精准
  • 得分低的题目会被优先重复出题
  • 题库和记录都存在浏览器本地，清除缓存会丢失
  • 换设备需要重新上传文档（或导出/导入题库）
