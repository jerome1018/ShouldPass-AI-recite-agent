# 深度学习面试题 — RoPE 位置编码

## 题目 1：RoPE 的基本原理

RoPE（旋转位置编码）的核心思想是通过旋转矩阵将位置信息注入到 token 的表示中。具体来说，对于注意力机制中的 query 和 key 向量，RoPE 会根据 token 的位置对它们施加一个旋转操作。这个旋转操作满足：两个向量旋转后的内积只依赖于它们位置的相对差值（m - n），而不是绝对位置。这使得模型能够自然地捕捉相对位置关系。

## 题目 2：为什么 RoPE 会长程衰减？

RoPE 长程衰减的根源在于其旋转机制。对于两个相距很远的 token，高位维度会经历大量的相位旋转，导致高频振荡。在 attention 计算中，这些高频振荡的 cos/sin 值在求和时会相互抵消（相位抵消效应），使得远距离 token 之间的 attention 分数自然衰减。这个衰减是 soft 的、由三角函数自然特性决定的，不需要额外引入衰减因子。

## 题目 3：RoPE 相比正弦位置编码的优势

1. 相对位置天然建模：RoPE 通过旋转使得 Q 和 K 的内积天然依赖于相对位置（m-n），而不需要像 Transformer 原始论文那样将位置编码加在输入上。2. 外推能力：RoPE 理论上可以外推到训练时未见过的长度，虽然实际中效果有限但比绝对位置编码好很多。3. 计算高效：RoPE 的旋转操作可以写成逐元素乘加，几乎不引入额外计算开销。
